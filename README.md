# PvP System

Fabric 26.1 mod for Soul SMP.

Features:
- Player-vs-player combat tags both players for 30 seconds; every hit refreshes the timer.
- Client-side gentle 50% aim assistance while locally in PvP, only within a 6-block range and 35-degree cone.
- Logging out during PvP causes lethal damage so normal death drops occur.
- `/bed` starts a 3-second stationary countdown and teleports to a valid bed spawn.
- Moving or entering PvP cancels `/bed`.
- Successful `/bed` use has a 5-minute cooldown.
